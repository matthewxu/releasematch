## 一、目录定位

| 维度 | `reviews/`（本目录） | `assessments/` | `iterations/` | `TRACKER-*.md` |
|------|---------------------|----------------|---------------|----------------|
| **内容** | GSC 原始数据 + 周期复盘 + 行动项 | 某时点 E-E-A-T/IG 快照评估 | 单次 SEO 专项改动记录 | Living 看板 |
| **更新频率** | 每次 GSC 复盘或里程碑 | 阶段切换 | 代码/策略变更时 | 持续 |
| **是否可改** | 复盘文档只增不改；同日复盘可追加 | 只增不改 | 只增不改 | 可更新 |

**原则：**

1. **按日期分子文件夹**：`reviews/YYYY-MM-DD/`
2. **原始数据进 `data/`**：GSC 导出的 CSV，不做手工改数
3. **分析文档编号**：`01-索引复盘.md`、`02-效果复盘.md`、`03-策略与TODO.md`
4. **每次复盘更新** [TRACKER](../TRACKER-E-E-A-T-InfoGain.md) §度量 与 §迭代日志

## 三、新建复盘规范

### 3.1 文件夹结构

```
reviews/YYYY-MM-DD/
├── README.md              # 当次复盘索引与核心指标
├── 01-GSC索引复盘.md       # 网页索引状态分析
├── 02-GSC效果复盘.md       # 展示/点击/查询/页面分析
├── 03-策略与TODO.md        # 策略结论与行动项（含优先级）
└── data/                  # GSC 导出 CSV（原样存放）
    ├── 查询数.csv
    ├── 网页.csv
    ├── 图表.csv
    └── ...
```

### 3.2 GSC 导出建议

每次复盘从 GSC **效果** 与 **网页索引** 分别导出：

| 报告 | 建议维度 | 文件名 |
|------|----------|--------|
| 效果 | 查询、网页、日期、国家、设备 | `查询数.csv` 等 |
| 索引 | 已编入 / 未编入原因 | 截图或 CSV |

### 3.3 复盘触发条件

- 每月固定复盘（建议每月 8 日）
- 重大变更后（开放爬取、sitemap 扩量、title 批量调整）
- 收录率或 CTR 出现 >20% 波动
